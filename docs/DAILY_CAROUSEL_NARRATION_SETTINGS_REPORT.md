# 日次5枚画像動画のナレーション設定

## 調査

日次の5枚投稿画像を30秒動画へ接続した時点では、動画は無音で作成されていた。個別動画には声・速さ・音声生成・原価記録・再試行が実装済みなので、新しい音声基盤を追加せず、サービスの毎日配信設定から既存経路へ接続する。

## 変更

- サービス運営者が、5枚画像動画のAIナレーションを有効または無効にできる。
- 有効時は、3種類の声と「ゆっくり／標準」の速さをサービスごとに保存する。
- 画像の見出しと説明から、各場面の表示時間に収まる短い読み上げ文を作る。画像に含まれる全文は変更しない。
- 自動動画へ`VOICE_SYNTHESIS`、選択した声、速さを渡し、既存のOpenAI音声生成、Creatomate合成、利用量記録を使う。
- 既存サービスは無音を維持する。画像を使わない字幕動画には、この設定を適用しない。

## 設計判断

- AI音声には追加費用が発生するため、初期値は無効とし、運営者の明示設定がある場合だけ生成する。
- 長い説明をそのまま読み上げると場面を超えるため、既存の上限である1秒3文字以内へ収める。画面上の投稿画像は既に完成しているため、短縮対象は音声台本だけとする。
- 設定は既存のサービス設定JSONへ追加し、DB Schemaとmigrationは増やさない。

## 本番確認

限定サービスでナレーションを有効にし、翌日の5枚画像動画について、選択した声・速さ、画像との切替タイミング、AI音声表示、LINE到達、iPhone再生を確認する。
