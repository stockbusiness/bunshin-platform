# 保存写真を毎日の自動画像へ適用

## 目的

利用者が「今日の素材」として保存した本人・商品・店舗等の写真を、画像プランの次回以降の自動投稿画像へ反映する。毎回の再アップロードを不要にし、無料利用者向けの投稿支援と画像プランの自動生成範囲を画面上で区別する。

## 実装

- 保存済み写真の履歴へ「毎日の画像に使う」を追加した。1分身につき1枚だけ選択でき、使用停止や別写真への切替も同じ画面で行える。
- 選択操作は、ログイン中の本人、対象サービス、対象分身、保存完了済み写真の一致をサーバーで再確認する。
- 自動画像生成時にも所有範囲と写真状態を再確認し、Private Storageから読み出して正規化した写真だけを生成依頼へ固定する。
- 生成用の参考写真は既存の期限付き参照保存と同じ経路へ複製する。別利用者の保存キーや公開URLを入力として受け付けない。
- 選択写真を取得・検証できない場合、その写真を使った画像生成は開始せず、通常の文章通知は継続できる。

## データ変更

`20260913150000_add_daily_image_reference_selection`で、本人素材へ自動画像用の選択状態を追加した。部分一意索引により、有効な選択写真はWorkspace・分身ごとに1枚に限定する。

## 提供範囲

この設定が画像本体へ反映されるのは、サービス運営者が画像または画像・動画の毎日準備を有効にし、利用者の支援レベルが完成内容の受取対象となる画像プランである。無料利用者は従来どおり、保存素材を投稿案・プロンプト作成の手助けとして利用できる。

本番Migration後に、iPhoneでの写真選択、翌日の自動画像、LINE到達、選択解除を実アカウントで確認する。
