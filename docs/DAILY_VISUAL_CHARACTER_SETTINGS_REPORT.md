# 日次投稿画像・動画のAIキャラクター設定

## 調査した内容

日次の自動動画は、完成した5枚投稿画像を場面順に使う。ここへAI動画場面を直接混ぜると、投稿画像と動画で内容と見た目が分かれ、現在の再利用経路とも両立しない。一方、投稿画像生成は安全に保存した参考画像を1枚受け取れるため、公開済みAIキャラクターの基準画像をこの入口へ接続できる。

## 変更したファイル

- サービスの毎日配信設定へ、AIキャラクターの使用可否と公開版IDを追加した。
- サービス管理画面に、利用可能な公開済みキャラクターの選択欄を追加した。
- 日次画像生成で、選択したキャラクターの基準画像を参考画像として利用するようにした。
- 毎日配信Jobから設定を画像生成へ渡した。

## 主要な設計判断

- キャラクターは画像生成時に適用し、その完成画像を既存の30秒動画へ引き継ぐ。これにより投稿画像と動画の見た目をそろえる。
- 既存サービスは初期状態で無効とし、運営者が明示的に選んだ場合だけ使用する。
- 参加者が自分の写真を次回画像用に選択している場合は、その明示的な選択を優先する。
- 実行時にもWorkspace、Service、公開状態、基準画像、商用利用、派生利用、再配布、利用期間を再確認する。条件を満たさない場合、キャラクターなしで勝手に生成せず、その回の画像生成を停止する。
- キャラクター原本の公開URLは作らず、非公開Storageから読み、画像生成依頼専用の参考画像として保存する。
- DB列は追加せず、既存のサービス登録設定JSONを利用する。

## 実行した検証

- 参加者が選んだ写真がキャラクター設定より優先されること。
- 有効なキャラクター基準画像が日次画像生成へ渡ること。
- 既存サービスの設定が無効・未選択として安全に読まれること。
- 型チェック、Lint、全テスト、本番ビルドを実行する。

## 未解決事項

- OpenAI画像生成、Creatomate、LINEを有効にした本番サービスで、キャラクターの見た目が5枚と動画で十分に保たれるかは実生成で確認する。
- 一つの画像依頼で使用できる参考画像は現在1枚である。複数キャラクターや商品写真との同時利用は対象外とする。
