# 運営者配信動画のLINE添付

## 目的

サービス運営者が参加者へ割り当てた完成動画を、確認リンクだけでなくLINE上で直接再生できる形で届ける。既存の本人向け完成通知と同じPrivate Storage、通知同意、接続確認、配信停止、Quota確認を利用する。

## 実装

- 運営者の動画配信通知へ、24時間の署名付きMP4 URLと共通の再生カバーを追加した。動画と確認リンクは同じLINE Pushに含める。
- Workspace、Service、受信者、Project、Render、Deliveryが一致し、完成済み・未削除・利用可能な動画だけを添付する。保存キーも受信者の所有範囲と完全一致させる。
- 動画または配信期限が24時間以内の場合と、既存通知の再送ではリンク通知を維持する。
- 初回の外部送信前に、宛先、認証情報のハッシュ、タイトル、確認リンク、署名付き動画URL、再送キーをDeliveryへ保存する。同時送信時は最初に保存された内容を採用し、再送時に本文や動画URLを変更しない。
- 通知Snapshotは通常のDelivery返却から除外し、配信取消・企画差戻し・退会処理では消去する。アクセストークンの平文は保存しない。

## データ変更

`20260913170000_add_video_delivery_notification_snapshot`で`video_deliveries.notification_snapshot`を追加する。既存行はNULLのため、過去通知の再送には動画を後付けせずリンク形式を維持する。

## 検証と運用

添付内容の固定、同時実行、宛先・認証変更拒否、旧通知互換、所有範囲、Storage Keyを自動テストする。本番Migration後、限定アカウントでLINE受信、動画再生、確認画面への移動を確認する。
