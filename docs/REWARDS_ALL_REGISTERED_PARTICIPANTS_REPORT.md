# ポイント・バッジ無料試験の全登録参加者対応

## 目的

無料試験の対象者を運営者が手動で選ぶ運用をやめ、対象Serviceへ登録して利用規約へ同意した一般参加者全員がポイントとバッジを利用できるようにする。

## 実装

- Serviceでポイント・バッジ機能と試験期間が有効な場合、利用中・規約同意済み・一般参加者のMembershipを自動で対象にする。
- 新しい一般参加者も、登録と規約同意が完了した時点で自動的に対象になる。
- ポイント管理画面から参加者選択フォームと30人表示を削除し、現在の対象人数を表示する。
- 参加者管理画面ではポイント・バッジの個別許可操作を表示せず、自動対象になる条件を案内する。
- 試験結果画面とCSVは、対象Serviceの登録済み一般参加者を集計する。

## 維持する制御

- Service単位の機能許可と試験期間
- ポイント付与の一括停止
- ポイント付与条件、交換条件、発行上限
- Workspace、Service、User、Membershipの境界
- 利用規約への同意確認

## 対象外

サービス所有者、運営管理者、コンテンツ担当者は、一般参加者として登録されていないため自動対象に含めない。

## 検証

- 対象Serviceの有効な方針だけでアクセスでき、参加者別Assignmentを要求しないこと。
- 別Workspace、別Service、同意前、停止中、一般参加者以外を対象にしないこと。
- 管理画面に参加者選択や30人上限の操作が残らないこと。
- 試験結果CSVが登録済み一般参加者を対象にすること。
