# ワタシワークス公式 初期設定レポート

更新日: 2026-09-14

## 設定する構造

```text
ワタシワークス全体（システム管理）
└─ 運営団体ワタシワークス（Workspace）
   └─ 企業向け（Project / Group）
      └─ ワタシワークス公式（公開サービス設定）
```

ワタシワークス全体はシステム管理だけを担当する。サービス利用者、投稿企画、ポイント、バッジ、LINE配信などの運用データは、必ず運営団体配下のプロジェクトに所属させる。

## 初期設定

- 運営団体: `運営団体ワタシワークス`
- プロジェクト: `企業向け`
- 公開サービス名: `ワタシワークス公式`
- URL識別子: `watashi-works-official`
- 対象: 企業、店舗、個人事業主
- 内容: 業種や商品に合わせた、コピーして使えるSNS投稿文を毎日LINEへ届ける
- 登録方法: LINE
- 配信初期値: 毎日 08:00、完成原稿、文章のみ
- 料金: 無料
- 有効機能: SNS投稿支援、LINE毎日通知

既存の千ノ国メディアを管理しているLINE認証済みのサービス責任者を、運営団体のOWNERおよび企業向けプロジェクトのSERVICE_OWNERとして明示的に登録する。別利用者のデータや権限は参照しない。

## 公開状態

初期状態は`PRIVATE`とする。次の項目を運営画面で確認するまで一般公開しない。

1. 問い合わせ先メールアドレス
2. 利用規約とプライバシー文書の公開版
3. ワタシワークス公式用LINEの経路と接続確認
4. LINE通知の利用開始

LINE通知の利用開始は、保存済み設定の確認後に運営者が実行する。初期設定Migrationでは通知を開始しない。

## 適用方法

Migration `20260914090000_seed_watashi_works_official_service`を適用する。対象運営者がまだ存在しない空の環境では処理を安全に見送り、既存設定と同じ識別子が別プロジェクトに存在する場合は誤更新を防ぐため適用を停止する。
